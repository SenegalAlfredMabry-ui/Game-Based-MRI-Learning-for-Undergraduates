# Changelog

## 0.1.0 — Initial public release — 2026-10-16

Five lessons, formally named game folders and setup scripts, reviewed teaching text, lesson-specific video galleries, instructional media, and a text feedback form. Scan conversion is Lesson 3; remote computing is Lesson 4.

The current documentation includes 16 instructional recordings, reflections from Lindsey Ko and Tiffany Huang, 25 figures and animations, and visible cheat sheets with printable PDFs for all five lessons. The five-card overview introduces the lessons on the homepage.

The standalone lesson ZIPs contain the validated game files. Complete MRI GUI workflows and Linux and Windows/WSL setup have not yet been verified end to end. Video transcripts remain drafts pending a complete audio check. Reflections for Lessons 1, 2, and 4 will be added when available.

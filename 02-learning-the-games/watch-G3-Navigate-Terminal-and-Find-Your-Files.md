## Using this example

Use `pwd`, short for print working directory, to see which folder you are in. To tell files and folders apart, use `ls -l`: a directory has `d` at the start of its permissions field. A name or file extension alone will not tell you whether something is a file or folder.

Use `cd ..` to move up to the folder containing your current folder. Use `cd -` to return to the folder you were working in before.

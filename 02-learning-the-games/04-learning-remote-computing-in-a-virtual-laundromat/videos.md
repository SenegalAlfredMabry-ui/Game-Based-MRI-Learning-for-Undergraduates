### Continuing the lesson

After the first two walkthroughs, continue with the written instructions for Rounds 3–5. You will practice repeating a task across several files and try simulated remote and cluster work. These activities run on your own computer; you do not need access to a remote server. If a command fails, Aaryan’s Getting Started video, [Work through an error and ask for help](../watch-G8-Work-Through-an-Error-and-Ask-for-Help.md), shows you how to check your location and the filename using an example from this lesson.

Learning Remote Computing in a Virtual Laundromat Stuck Instructions
===============================

The main round files are written as guided challenges. They tell you what goal
to accomplish and which folders, scripts, or command ideas to use.

Use these stuck instructions only after you have tried the guided version.

Files in this folder:

    Round_1_Local_Washer_STUCK.txt
    Round_2_Too_Much_Laundry_STUCK.txt
    Round_3_Robot_Washer_Loop_STUCK.txt
    Round_4_PI_Laundromat_STUCK.txt
    Round_5_Laundry_Cluster_Job_STUCK.txt

How to use them:

1. Read the guided round first.
2. Try to build the command yourself.
3. If you are stuck, open the matching stuck file.
4. After you use the stuck file, write down what part you needed help with.

The point is not to avoid help. The point is to notice what kind of help you
needed so you can solve a similar problem more independently next time.

Round 4 - PI Laundromat
=======================

Goal
----

Practice the ideas behind logging into a remote computer and copying files to
it.

In real research, this might be a server or computing cluster. In this game, it
is a fake folder called:

    remote_laundromat

What this teaches
-----------------

ssh means: connect to another computer.
scp means: copy files to another computer.

In this game, both are simulated with scripts.

Laundry analogy:
Imagine you have too much laundry for your small washer at home, or you have
special dry-clean-only clothes that your home washer should not handle. You need
to go somewhere else: a laundromat or dry cleaner with bigger machines and
special equipment.

Remote research analogy:
MRI data can be too large or too computationally demanding for a normal laptop.
Instead of doing everything "at home" on your own computer, researchers log into
another computer, server, or cluster that has the data, software, storage, and
processing power needed for the job.

In this round:

    fake_ssh.sh = pretending to log into the PI Laundromat
    fake_scp.sh = pretending to send files to that remote place
    remote_washer.sh = pretending to process files on the remote computer

Step 1 - Fake login
-------------------

Find the fake SSH script in the scripts folder.

Run it with bash and give it the remote address:

    student@pi-laundromat

When it asks for the password, use the password from this round:

    spin-cycle-42

Question:

    What is the game pretending to do when it asks for a remote address?

Step 2 - Look at the remote load
--------------------------------

List the files in:

    dirty_laundry/round4_remote_load

This is the laundry that needs the PI Laundromat instead of the local washer.

Step 3 - Send files to the PI Laundromat
----------------------------------------

The fake SCP script needs two arguments:

    source folder
    destination folder

Build the command from these pieces:

    bash
    scripts/fake_scp.sh
    dirty_laundry/round4_remote_load
    remote_laundromat/incoming

If you are stuck, read:

    cat instructions/stuck_instructions/Round_4_PI_Laundromat_STUCK.txt

Step 4 - Check the remote incoming folder
-----------------------------------------

Inspect:

    remote_laundromat/incoming

Question:

    Why does the remote computer need the files before it can process them?

Step 5 - Run the remote washer
------------------------------

Find the remote washer script inside:

    remote_laundromat/bin

Run that script with bash.

Step 6 - Check remote outputs
-----------------------------

Inspect:

    remote_laundromat/clean_laundry

Then run the remote laundry checker.

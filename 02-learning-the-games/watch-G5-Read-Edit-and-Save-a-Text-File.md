## Using this example

To leave nano, press `Ctrl+X`. If it asks whether to save your changes, press `Y`, then `Enter` to accept the filename. You can open nano’s help with `Ctrl+G`.

Carlo uses WSL on Windows. You may notice FreeSurfer startup text on his screen; you do not need FreeSurfer for the House activity.

## Using this example

You will often see shell scripts with names ending in `.sh`. The ending is a naming convention; read the file to see which commands it contains.

For this example, go to the folder containing the script and run `bash sort_round2.sh`. John runs it as `./sort_round2.sh` in MSYS2. That form also requires permission to execute the file and an appropriate command interpreter.

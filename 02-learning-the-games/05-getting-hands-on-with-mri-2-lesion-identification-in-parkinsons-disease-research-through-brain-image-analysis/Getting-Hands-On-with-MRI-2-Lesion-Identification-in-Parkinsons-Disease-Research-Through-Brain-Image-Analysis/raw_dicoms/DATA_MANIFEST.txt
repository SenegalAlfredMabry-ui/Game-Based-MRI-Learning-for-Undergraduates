Lesson 5 DICOM Data Manifest
============================

Each teaching subject starts with two DICOM ZIP files:

    MPRAGE_DICOM.zip
    FLAIR_DICOM.zip

Students unpack them with:

    bash scripts/unpack_dicoms.sh

After unpacking, each teaching subject has two DICOM folders:

    MPRAGE_DICOM
    FLAIR_DICOM

Expected file counts:

    MPRAGE_DICOM: 200 DICOM files
    FLAIR_DICOM: 44 DICOM files

Teaching note
-------------

The ZIP files contain raw DICOM files. Students need to unpack the scan ZIPs,
then run the DICOM-to-NIfTI conversion step before opening the images as NIfTI
files in ITK-SNAP.

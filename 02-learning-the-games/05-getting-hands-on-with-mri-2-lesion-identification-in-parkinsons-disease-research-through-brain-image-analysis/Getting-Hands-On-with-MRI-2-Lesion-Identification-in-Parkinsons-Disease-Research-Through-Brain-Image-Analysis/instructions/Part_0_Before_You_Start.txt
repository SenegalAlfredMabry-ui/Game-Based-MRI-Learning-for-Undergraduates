Lesson 5: Part 0 - Before You Start
===================================

Goal:
Make sure you are in the correct folder, understand what data is present, and
know which external tools are needed before starting the capstone workflow.


How this game is split
----------------------

This is one capstone game with two parts.

Part A: Setup, conversion, and opening images
    Complete Part 0, Part 1, Part 2, and Part 3.
    Your goal is to get from folders and DICOMs to FLAIR/MPRAGE images that open
    in ITK-SNAP.

Part B: Masking, measurement, and group comparison
    Complete Part 4, Part 5, and Part 6.
    Your goal is to paint lesion-like hyperintensity masks, measure them, and
    compare the PD and control groups.

Recommended pacing:
    Do Part A first. Pause when everyone can open at least one subject in
    ITK-SNAP. Start Part B after students have had time to ask questions about
    image orientation, contrast, and what they are supposed to mark.


Step 1 - Enter the game folder
------------------------------

If the unzipped folder is on your Desktop, run:

    cd ~/Desktop/05-getting-hands-on-with-mri-2-lesion-identification-in-parkinsons-disease-research-through-brain-image-analysis

If it is inside another folder, use cd to move into that folder instead.


Step 2 - Check where you are
----------------------------

Run:

    pwd
    ls

You should see:

    README.txt
    FAQ.txt
    SOFTWARE_SETUP.txt
    subject_groups.csv
    raw_dicoms
    converted_niftis
    lesion_masks
    results
    scripts
    instructions
    student_notes

You may also see an instructor_notes folder. That one is for your instructor.

Pause question:
    Which folder do you think will hold the files you create later?


Step 3 - Check the included DICOM data
--------------------------------------

Run:

    ls raw_dicoms
    ls raw_dicoms/sub-PD01

This version includes DICOM files as ZIPs. Keeping the DICOMs zipped makes the
game easier to download and keeps the folders cleaner before students are ready
to convert the images.

You should see:

    MPRAGE_DICOM.zip
    FLAIR_DICOM.zip

Then unpack all scan ZIPs:

    bash scripts/unpack_dicoms.sh

The unpacked file names will look long and strange; that is normal for DICOM
data.

For a quick count after unpacking, run:

    find raw_dicoms/sub-PD01/MPRAGE_DICOM -name "*.dcm" | wc -l
    find raw_dicoms/sub-PD01/FLAIR_DICOM -name "*.dcm" | wc -l

You should see about:

    MPRAGE_DICOM: 200 files
    FLAIR_DICOM: 44 files

The full source mapping is in:

    cat raw_dicoms/DATA_MANIFEST.txt


Step 4 - Check external tools
-----------------------------

This game uses:

    dcm2niix
    ITK-SNAP
    python3

Run:

    command -v dcm2niix
    command -v python3

If a command prints nothing, that tool is not available in your current
Terminal. Ask your instructor whether you should install it, load a module, or
use a full path.

Then open ITK-SNAP as a regular app. ITK-SNAP does not always install a
Terminal command, so it is okay if `command -v itksnap` prints nothing.

Read the setup guide before guessing:

    cat SOFTWARE_SETUP.txt

Pause question:
    Which tools run in Terminal, and which tool opens like a regular app?


Step 5 - Setup checkpoint
-------------------------

Before moving on, you should be able to answer:

1. Did `dcm2niix -h` show help text?
2. Did `python3 --version` print a version?
3. Did ITK-SNAP open?
4. Do you know where the DICOM ZIP files are?
5. Do you know where converted NIfTI files should be saved?

Pause and record setup notes:

    nano student_notes/part0_setup_reflection.txt

Use this setup checkpoint before moving on. The point is not to have perfect
software knowledge yet. The point is to notice whether the tools are available
before you need them for real image work.

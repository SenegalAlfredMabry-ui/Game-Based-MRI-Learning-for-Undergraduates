# Check the tools for your lesson

Aaryan Sajwani · 3:13 · macOS example

Before starting a lesson, check that your computer has the tools it needs. Aaryan takes you through those checks. He checks Bash and Python, locates dcm2niix, and opens an MRI viewer. Follow your lesson’s software instructions to see which of these tools you will need.

## Using this example

Aaryan uses macOS, so `sw_vers` and `open -a` may not work on your computer. Follow the instructions for your platform. For the MRI lessons, you will use MRIcron in Lesson 3 and ITK-SNAP in Lesson 5. You do not need an MRI viewer for Lessons 1, 2, or 4.

Seeing a program’s version or help text tells you that it can be found and launched. When you use it in a lesson, also check the files it produces.

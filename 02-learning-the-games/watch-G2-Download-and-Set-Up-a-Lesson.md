## Using this example

Katie uses macOS in this video. Follow the setup instructions for your own computer and use the folder names in your downloaded lesson. When you reach the setup step, the full command is `bash setup_Learning-Unix-Basics-in-a-Virtual-House.sh`. Run it from the folder containing that script, then open the generated game folder and read `README.txt`.

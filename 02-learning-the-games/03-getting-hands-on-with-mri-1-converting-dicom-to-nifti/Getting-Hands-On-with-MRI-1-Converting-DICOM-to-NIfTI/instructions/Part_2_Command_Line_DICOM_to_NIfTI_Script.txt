# PART 2 - Command-Line DICOM-to-NIfTI Script

## Goal

Build a short script that converts the MPRAGE and FLAIR DICOM folders into NIfTI
files with dcm2niix. Then review the scripted outputs in MRIcron using the same
MPRAGE, FLAIR, contrast, and overlay process from Part 1.

Part 2 is about moving from a GUI workflow to a reproducible code workflow.

---

## Step 1: Create the script output folder

Use what you learned from the Learning Unix Basics in a Virtual House to create a folder named:

    script_niftis

Check your work with ls.

Expected purpose:
The script should put all command-line NIfTI and JSON outputs in script_niftis.

Expected output names:

    script_niftis/sub-001_MPRAGE.nii.gz
    script_niftis/sub-001_MPRAGE.json
    script_niftis/sub-001_FLAIR.nii.gz
    script_niftis/sub-001_FLAIR.json

Checkpoint:
Why are we using a different folder from gui_niftis?

Use nano to open:

## Step 4: Read the variables

Find the variables:

    SUBJECT
    DICOM_ROOT
    OUT_DIR

Do not skip this part. These variables control the subject, the input folder,
and the output folder.

Expected values for this game:

    SUBJECT should point to sub-001
    DICOM_ROOT should point to raw_dicoms/sub-001
    OUT_DIR should point to script_niftis

Checkpoint:
If the next subject were sub-002, which variable would you change first?

## Step 6: Break down the MPRAGE command

Find the MPRAGE dcm2niix command.

Identify these parts:

    -z y
    -b y
    -f "${SUBJECT}_MPRAGE"
    -o "$OUT_DIR"
    "$DICOM_ROOT/MPRAGE_DICOM"

Hints:

    -z y controls compression
    -b y controls JSON metadata
    -f controls the output filename
    -o controls the output folder
    the final path is the input DICOM folder

Checkpoint:
Which part names the output file? Which part chooses the input DICOM folder?

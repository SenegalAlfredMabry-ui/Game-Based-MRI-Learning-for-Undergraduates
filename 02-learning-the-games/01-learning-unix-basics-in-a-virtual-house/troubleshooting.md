# Troubleshooting

Read the entire error message, check your location with pwd, and list the relevant folder with ls. Compare the command with the lesson instructions, including capitalization, spaces, quotation marks, and filenames. Keep a copy of the message so you can describe the problem accurately.

If Terminal cannot find a room, check whether your path starts from your current directory or from the root of the filesystem. If a moved object seems missing, inspect the destination named in the command. If the smoothie is empty or incomplete, read the ingredient files, examine the input pattern, and open the script before running it again.

Describe the lesson and step, what you expected, what happened, and the exact command or error. Share text after removing identifying details. Avoid resetting the entire activity while the cause is still unclear; preserve your work so the problem can be understood.

# Contributing

## Contributing

You can contribute by reporting a problem, suggesting clearer wording, improving an example, or offering a reflection video through the project’s contribution route. For code or documentation changes, explain the problem and the behavior your change is intended to improve. Include enough detail for another person to reproduce a reported issue.

Use the repository feedback form to report a problem or suggest an improvement. Reflections are videos; contact sam469@cornell.edu to arrange sharing. Lesson galleries feature recordings only after review.
